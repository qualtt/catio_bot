# 🐾 Catio Bot

Telegram-бот для автоматизированного сбора, модерации, оценки и публикации фотографий животных в канал. Бот содержит продвинутую геймификацию, включая еженедельные и ежемесячные турниры с автоматической генерацией турнирных сеток, систему рейтинга и проверку изображений нейросетью.

## 🌟 Основные возможности

- **Умная загрузка фото**: Подписчики присылают фотографии, бот автоматически проверяет их на дубликаты (используется хеширование `pHash` и `SHA256`).
- **Модерация и ИИ (Gemini)**: Бот может использовать нейросеть для автоматического определения вида животного и отбраковки мусора перед тем, как фото попадет к модераторам.
- **Продвинутая геймификация и Турниры**: 
  - Еженедельные и ежемесячные турниры по системе плей-офф среди опубликованных фото. 
  - Автоматическая отрисовка **красивых турнирных сеток (brackets)** с фотографиями победителей.
  - Топ пользователей (лидерборд) по заработанным очкам, количеству фото и победам в турнирах.
- **Панель администратора**: Удобный Dashboard внутри Telegram для модерации, назначения слотов публикаций и управления отложенными постами.
- **Надежное хранение (S3)**: Изображения сохраняются в S3-совместимое объектное хранилище (MinIO/AWS/S3), в БД лежат только ключи и метаданные.

## 🛠 Технологический стек

- **Язык**: Python 3.11+
- **Фреймворк**: [aiogram 3.x](https://docs.aiogram.dev/)
- **База данных**: PostgreSQL (SQLAlchemy 2 + Asyncpg)
- **Миграции**: Alembic
- **Работа с изображениями**: Pillow (PIL), ImageHash
- **Инфраструктура**: Docker & Docker Compose, GitHub Actions для CI/CD

## ⚙️ Установка и запуск

Проект легко разворачивается с помощью Docker.

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/qualtt/catio_bot.git
   cd catio_bot
   ```

2. **Настройте окружение:**
   Скопируйте пример файла конфигурации:
   ```bash
   cp .env.example .env
   ```
   Отредактируйте `.env` и укажите ваши данные:
   - `BOT_TOKEN` — токен бота от @BotFather.
   - `ADMIN_ID` — ваш Telegram ID.
   - `CHANNEL_ID` — юзернейм или ID канала для публикаций (например, `@my_channel`).
   - Настройки базы данных (`POSTGRES_*`) и S3-хранилища (`S3_*`).

3. **Запустите проект:**
   ```bash
   docker-compose up -d --build
   ```
   БД поднимется автоматически, скрипт запуска применит все актуальные миграции `alembic upgrade head` и запустит бота.

## 📁 Структура проекта

- `bot/` — Основной код Telegram-бота:
  - `handlers/` — Обработчики команд, кнопок и сообщений.
  - `services/` — Бизнес-логика (турниры, модерация, турнирные сетки, интеграция с Gemini).
  - `keyboards/` — Inline и Reply клавиатуры.
- `db/` — Модели SQLAlchemy (`models/`) и CRUD-операции (`crud/`).
- `alembic/` — Настройки миграций базы данных.
- `tests/` — Юнит-тесты на pytest.
- `bot_content.json` — Все переводы и тексты бота. Вынесены в отдельный конфиг для удобного редактирования без изменения кода.

## 📝 Разработка и тестирование

Для локальной разработки потребуется виртуальное окружение:

```bash
python3.11 -m venv .venv
source .venv/bin/activate

# Установка зависимостей
pip install -r requirements.txt -r requirements-dev.txt

# Запуск тестов
PYTHONPATH=. pytest tests/

# Проверка кода линтером
ruff check .
```
